# 小说AI资产准备、排版与出图

适用版本：1.1.0-comic.8及以上；1.1.0-comic.9增加JSON语法纠错重试。

## 操作顺序

1. 在“API管理”配置想使用的AI服务。小说界面设置可选择具体连接或跟随当前连接；支持现有OpenAI兼容/Google传输。不自动启动本地LLM，不内置任何服务的密钥。
2. 在“设置 → 漫画连接”确认Python、ComfyUI、工作流和输出目录。
3. 打开“小说漫画”，导入TXT或EPUB，进入该作品。
4. 打开右上角小说设置，选择“AI创作与布局匹配”，选模型连接，填写每章页数、画风和创作要求。格数由AI所选布局决定。LoRA、步数、CFG、种子会作为接力初始值，接力中仍可调整及多选LoRA。
5. 点击“准备资产”。程序分段扫描完整原文，积累角色卡、明确别名、场景卡、关键道具和事件摘要。每段完成即保存，失败或暂停后可继续，不必重扫已完成段。
6. 在“文字资产”检查原文明示的身份/外貌/基础服装与“视觉补设”。有可匹配原文证据不等于内容已被人工证实；无匹配证据会标为待核对。编辑后的卡自动保存并保留手工设定。
7. 点击“AI自动排版”。若资产未完成会先继续资产准备，然后逐页选择布局、给出文字构图备选与选择理由、填写每格描述、镜头及台词。每页成功才计入进度。
8. 查看漫画页的实际格形和分镜编辑。可以“AI修改当前页”，或逐格手工编辑。AI重设计前保存该页修订副本，其他页面不重做；改后需检查后续剧情连续性。
9. 交付方式二选一：
   - **自行复制提示词**：排版后进入提示词页，可复制整页MOSS提示词、各格提示词和台词清单，也可导出全书JSON/Markdown。整页或逐格使用时同步设置相应画幅。此模式不调用ComfyUI。
   - **用我的工作流**：在小说设置中选择自己的兼容MOSS API JSON，或留空沿用漫画连接的工作流。排版后进入接力面板，确认参数再开始。首次选择工作流会读取其中的采样参数与LoRA链；后续可在面板多选/调整。默认逐格蒙版拼接，可在单页/多页之间选择。
10. 使用“成品预览与导出”入口检查图片版本，导出CBZ/PDF。

“AI自动排版”完成的是文字方案与真实坐标布局，尚未生成图片，不声称完成视觉草稿或成图审阅。

“用我的工作流”目前使用MOSS专用API节点接口：1基础模型、2模型采样、5正面、6负面、7 EmptyFlux2LatentImage、8 KSampler、11 SaveImage，模型LoRA链使用LoraLoaderModelOnly。可使用已有中文工作流导出的对应API文件，或包内 `workflows/moss-8step-12steps-cfg2-api.json` 示例。不同节点编号、任意第三方图或界面格式JSON不自动猜测接线，无法兼容时明确报错。后端会替换当前页提示词、画幅、种子、步数、CFG、输出前缀及面板选中的LoRA链，其他兼容节点保留，并冻结保存实际执行图。

8步加速示例使用 `moss_sft_8step_dmd_latest.safetensors` 强度0.7、muqiu画风0.75、实际12步、CFG2；模型需用户自行准备，包内不含权重。只复制提示词时不需要配置本机ComfyUI。

## 121套布局如何使用

目录由15类构图各8种几何变体，加一套整页构图组成，不宣称121种独立叙事理论。包括上下双拍、左右对峙、横向连续拍、上/下/左/右主画面、对白与反应、多人物反应、斜切动作、嵌入细节等。

点击“121套布局目录”可按编号或对白、动作、悬念、静场等关键词查看。AI收到全部编号、标签和阅读顺序外框比例，返回选定编号及独立格描述；程序根据实际画幅生成坐标。非法编号、漏写格描述、格数不匹配会暂停本页，不会静默改成四格。

自动选择不保证审美质量。允许有目的地重复格网与景别，不为了多样化随机轮换。候选构图文字也不等于已经绘制和比较了视觉草稿。

## 文字角色一致性

- 已有基础角色卡优先，AI不会每页随意替换原先的发型、服装约定；同名及明确别名尽量归并。
- 分镜阶段发现资产扫描遗漏的角色，可补建“待核对”的卡，不能把模型臆造的细节当原文事实。
- 换装、伤势、持有道具和动作位置需要记入本页描述与剧情状态；基础卡只是长期约定。
- 手工修改会用于后续页与新的接力快照；已经冻结或生成的旧任务不随之自动改图。
- 卡片是文本提示约束，不是图像身份锁。真正的跨页脸部/体型一致性仍需适配参考图或角色LoRA，并实际看图验证。

## 暂停、继续与重新规划

从comic.9起，AI答复出现JSON语法错误时会自动纠错重试一次。程序只自动处理字符串外的尾逗号，不改变台词，不补造括号、人物事实或格数；纠错仍失败则暂停。模型纠错会产生一次额外API请求，用量以服务商为准。取消、网络失败和布局字段校验失败不会触发这一语法纠错请求。

AI任务点击停止图标后，已完成资产段和页面保留。重启软件不会自行发起模型请求；再次准备资产或“继续AI排版”会接续保存的进度。

改变原文、每章页数、画风或创作要求后，不继续混用旧页计划；使用“重新规划”创建新一轮。旧页面文件保留。单页修改仅调整选中页，重新规划则切换整轮页列表。

原文按句/段落附近边界连续分配到指定页数，不丢弃原文；AI结合当前片段、章节事件摘要、人物卡与前页记忆做具体分镜。它尚不是可无限上下文理解整本长篇、完全自由重排全部章节的导演系统。单页原文过长会提示增加每章页数，而不是悄悄截掉。

## 输出与验证

小说工作区位于实际数据目录的 `novel-comic/`，每个作品有独立输出目录。`assets.json` 保存文字资产，AI每页保存 `page.json`、计划状态manifest及布局编号；渲染任务和图片仍进入漫画连接配置的输出目录。不要将这些用户资料提交公开仓库。

本轮用Luna子代理实际创作了正常着装成年人物的资产与两页文字分镜，再通过程序解析、几何预览和接力快照检查。测试覆盖断点恢复、错误拒绝、手工修改、文字卡保留及121套几何。本轮未以真实外部云端API完成整套流程，也未对这些新页面生成成品图片。现有MOSS逐格出图样张与说明见 [操作指南](操作指南.md)。

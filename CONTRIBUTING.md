# Contributing

Use an independent PENNA_HOME for development. Do not use personal novels,
chats, credentials or production artwork in tests or examples.

Follow README.md for Flutter and Python checks. Set PENNA_TEST_PYTHON to the
Python executable in your test environment. Backend changes must preserve
submission-uncertainty protection and avoid duplicate ComfyUI submissions.

Keep configuration portable. Do not add machine-specific absolute paths or
implicitly start, terminate or unload externally managed services.
Report exactly which checks ran; model quality claims require separate
generation evidence. Public releases require a clean Windows build, notice
review and cross-machine acceptance.
